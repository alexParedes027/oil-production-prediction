# Presentación

Presentación final del proyecto: pronóstico de producción de petróleo no convencional para agosto de 2026, pensada para una audiencia de gestión sin conocimientos de estadística. Dura unos 12 minutos más preguntas y la presentan Alex Paredes y Julián Varela.

| Archivo | Uso |
|---|---|
| `presentacion.pptx` | Para presentar desde PowerPoint, Keynote o Google Slides. Las diapositivas son imágenes, por lo que el texto no se puede editar. |
| `presentacion.pdf` | Para compartir o imprimir. |
| `presentacion.html` | Se abre en cualquier navegador. |

Los números de la presentación provienen de las notebooks 04 (regresión, modelo de 24 meses), 05 (clasificación) y 07 (clustering jerárquico).
